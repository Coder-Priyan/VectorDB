# IBM Plex Fonts (Local Offline Assets)

This directory contains local `.woff2` font files for the VectorDB web interface.

## Sources & Versions
- **IBM Plex Sans**: v1.1.0 (Official package `@ibm/plex-sans` via https://github.com/IBM/plex)
  - `IBMPlexSans-Regular.woff2` (Weight: 400)
  - `IBMPlexSans-Medium.woff2` (Weight: 500)
  - `IBMPlexSans-SemiBold.woff2` (Weight: 600)
- **IBM Plex Mono**: v2.5.0 (Official package `@ibm/plex-mono` via https://github.com/IBM/plex)
  - `IBMPlexMono-Regular.woff2` (Weight: 400)
  - `IBMPlexMono-Medium.woff2` (Weight: 500)
