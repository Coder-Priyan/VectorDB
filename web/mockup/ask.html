The self-attention mechanism computes attention weights by first projecting input token vectors into query (Q), key (K), and value (V) matrices [1]. The attention weights are calculated as the scaled dot-product between queries and keys, divided by the square root of the key dimension to prevent numerical instability in large dimensions [2]. Applying the softmax function yields a normalized probability distribution over all positions, which is then used to weight the value vectors to produce the contextualized token representation [3].

An attention function can be described as mapping a query and a set of key-value pairs to an output, where the query, keys, values, and output are all vectors. The output is computed as a weighted sum of the values, where the weight assigned to each value is computed by a compatibility function of the query with the corresponding key.
