The self-attention mechanism computes attention weights by first projecting input token vectors into query (Q), key (K), and value (V) matrices [1]. The attention weights are calculated as the scaled dot-product between queries and keys, divided by the square root of the key dimension \(\sqrt{d_k}\) to prevent numerical instability in large dimensions [2]. Applying the softmax function yields a normalized probability distribution over all positions, which is then used to weight the value vectors to produce the contextualized token representation [3].
