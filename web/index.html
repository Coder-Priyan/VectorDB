VectorDB - Semantic Search Engine ONLINE v0.4.0

The VectorDB C++17 REST API server is running and ready to process vector insertions, approximate nearest-neighbor queries, multi-algorithm benchmarks, and HNSW graph introspection.

Available REST API Endpoints

Method Endpoint Description
GET /api/health Server status & version check
GET /api/config Current collection dimension, metric, and HNSW parameters
POST /api/reset Reset collection and optionally reconfigure parameters
GET /api/stats Vector count, dimension, and metric
POST /api/vectors Insert single vector with optional ID and metadata
POST /api/vectors/batch All-or-nothing batch vector insertion
GET /api/vectors/:id Retrieve vector components and metadata by VectorId
POST /api/search Search top-k neighbors (BruteForce, KD-Tree, HNSW)
POST /api/benchmark Run query against all three algorithms simultaneously
GET /api/hnsw/info HNSW multi-layer graph topology overview
GET /api/hnsw/node/:id Inspect node layer presence and neighbor connections
POST /api/hnsw/trace Detailed step-by-step distance traversal trace
POST /api/demo/random Generate and insert N synthetic Gaussian vectors
